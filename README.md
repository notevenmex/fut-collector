# FUT Portfolio Collector

Tampermonkey userscript for the EA FC web app. It reads your Transfer List and Transfer Targets and sends them to your own Google Sheet. It never buys, bids, lists, relists, quick-sells or clears anything.

Install: open the raw [fut-collector.user.js](https://raw.githubusercontent.com/notevenmex/fut-collector/main/fut-collector.user.js) with Tampermonkey installed. Tampermonkey checks this URL for new versions.

The web app URL and secret are set from the Tampermonkey menu ("Set web app URL and secret") and are never stored in this file.
